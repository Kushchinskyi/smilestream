# Краткая инструкция — кандидат Smile Stream 2.0

Рабочий сайт ещё не заменён. Локальная версия подключается только к отдельному test Supabase. Сохранить приватный smile-integration.local, пароль не копировать в Git/чат.

Из PowerShell в папке проекта:

```powershell
node scripts/start-integration-test.mjs --lan
```

Если порт 4173 уже занят работающим preview, используйте его либо завершите именно старый launcher; не запускайте два сервера на одном порту. Команда пересобирает изолированный preview. Компьютер: `http://127.0.0.1:4173/admin`, TV: `http://127.0.0.1:4173/tv`. Samsung в той же LAN: `http://192.168.31.27:4173/tv` (адрес Ethernet на момент подготовки; сверить `ipconfig` после смены сети). Разрешить входящий TCP 4173 только в доверенной частной сети; не настраивать public port forwarding.

Авторизация — существующая тестовая учётная запись; пароль смотреть локально в smile-integration.local. На TV вход не нужен. После запуска пульта/видео не требуется повторять длительный рекламный тест: пользователь уже подтвердил этот сценарий.

Контент смотреть в `content/videos.csv` и `content/music.csv`; их не нужно загружать в текущий audio import. Они являются каталогом проверки. Пошаговый выпуск и необходимые разрешения — LOVABLE_RELEASE_PLAN.md. Не нажимать Publish, не применять SQL и не merge PR до отдельного согласования.

## UX backlog, без нового редизайна

- Пользователь подтвердил улучшение интерфейса, но конкретные новые визуальные замечания в текущем сообщении не перечислены; не приписывать ему выдуманные дефекты.
- Подтверждённые ограничения: добавление видео по одному; audio import не восстанавливает всю библиотеку; новая offline-подготовка ещё не DB executor.
- Сохранение video/metadata/audio не одна транзакция; при частичной ошибке читать сообщение и повторять с той же записью. Пока использовать одного редактора настроек одновременно.
- Pairing/heartbeat/per-screen настройки пока не реализованы: «дані відсутні» — корректное состояние.
- Responsive smoke на пяти ширинах и новые скриншоты не выполнены из-за сохранённого запрета browser tool. Подтверждённый пользователем Samsung UX не заменяет эту desktop/mobile проверку.
