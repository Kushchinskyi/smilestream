## Видео

- `mixkit-audit.json`: 95 уникальных страниц, 17 Free License, 43 Restricted (исключены), 35 HTTP 429 (не подтверждены, повторные запросы остановлены). У 17 Free прямой MP4 отвечал HTTP 200. **Все 17 уже присутствуют среди 25 production-видео**: новых материалов из них нет. Дубликаты нельзя включать в счётчик расширения библиотеки.
- `video-candidates.json` / `videos.csv`: 12 новых уникальных Pexels-кандидатов с авторами, источниками, лицензией, прямыми HTTPS MP4 и реальными ffprobe-метаданными. 3 H.264 HD (обработка протеза, панорамная диагностика, работа лаборатории); 9 требуют нормализации из 4K/вертикального формата. Оригинальный звук по умолчанию OFF. Не выдаём supporting footage инструментов/интерьера за CAD/CAM или SLA.
- H.264/yuv420p/HD и AAC-LC либо silent — консервативный профиль для двух декодеров Chromium 85. Не гарантия Samsung playback: новые материалы нужно коротко проверить на реальном ТВ. 4K Level 5.2 не исключается по лицензии, но требует собственного разрешённого производного HD-файла и повторного probe.
- Прямые CDN URL не содержат подписи/expiry query, однако это не гарантия бессрочного hotlinking/SLA. До импорта согласовать hosting, вручную получить разрешённые исходники и сохранить лицензии/источники. Не делать массовое скачивание Mixkit в нарушение Terms.

Ориентир 95 **новых качественных** роликов пока не достигнут. Исключены Restricted, платные iStock-вставки Coverr без разрешения, generic FDM вместо SLA, случайная операционная хирургия. Не найдено достаточно подтверждённых свободных реальных CAD/CAM, фрезерования, SLA/DLP/MSLA, wash/cure, guides и zirconia-процессов. Для этих направлений следующий качественный источник — собственная съёмка клиники/лаборатории или письменные права от производителя (Formlabs/3Shape/Dentsply Sirona); публичный YouTube не даёт права переиспользования. Не покупать материалы без отдельного согласования. Существующий CEREC URL и Pixabay-пункты сохранены, права на них требуют отдельной проверки, ничего не удалено.

Реальные длительности есть для 29; catalogDuration — справочное значение источника.

Ambient/piano/synth отобраны по инструментам/описаниям, **не по завершённому прослушиванию**. Не измерены loudness/peaks, не подтверждено отсутствие резких переходов/вставок во всех файлах. Для первой ротации: Peace of Mind, Wisps of Whorls, Ambiment, Tranquility Base, Almost in F, Fluidscape, Deep Relaxation, Organic Meditations One/Three, Clean Soul, Dream Culture, Meditation Impromptu 01/02, Air Prelude, Gymnopedie No.1 — свыше четырёх часов по каталогу, финальный состав после прослушивания.

Лицензия источника — CC BY 4.0 с обязательной доступной публике атрибуцией. Поле attribution подготовлено для печатной карточки/QR-страницы кредитов клиники; запись только в закрытой админке недостаточна. Указать изменения после обработки. [CC BY 4.0 legalcode](https://creativecommons.org/licenses/by/4.0/legalcode.en) допускает коммерческое sharing/public performance, но сохраняет неотчуждаемые сборы collecting societies. Нужно подтвердить применимые права публичного воспроизведения в юрисдикции клиники; бесплатная загрузка не означает полного освобождения от местных сборов. Поэтому `publicPerformanceClearanceApproved=false`, автоматической загрузки музыки нет. Альтернатива без attribution — платная лицензия источника только по отдельному согласию, не куплена.

## Безопасная подготовка массового импорта

Текущая админка добавляет видео по одному; audio import меняет черновик настроек и не является append-only импортом всей видеотеки. Новый offline planner готовит **план**, не исполняемый Supabase/админкой файл:

```powershell
node scripts/prepare-content-import.mjs content/video-candidates.json release-backup.local/production-app-data.json content-import.local.json
node --test scripts/content-import-plan.test.mjs
```

Нужен свежий приватный экспорт существующих videos (массив или объект с videos). План проверяет HTTPS без credentials/query, поля/категории/длительности, provenance/license, дубликаты в партии и библиотеке (включая разные разрешения одного Pexels/Mixkit ID), оригинальный звук и review gates. Только новые disabled-строки после максимального sort_order; существующие строки/музыка/громкость/IDs не меняются. Размер входа ≤2 MiB, ≤500 кандидатов; output создаётся исключительно новым `*.local.json`, без перезаписи. Нет API, SQL, чтения env или credential file. Не исполнять JSON как SQL.

Сейчас все 12 корректно попадают в held: ожидаются visualReviewApproved и hostingApproved, а для девяти — нормализация. Эти флаги менять только после фактической проверки соответствующего файла. После повторной генерации и согласования добавлять разрешённые строки в TEST сначала неактивными, сверять counts/order и включать по отдельности. DB executor/кнопка массового импорта не добавлены: транзакционный исполнитель и отдельное подтверждение production остаются будущим шагом. Музыку append к существующему черновику вручную с проверкой дубликатов; не импортировать 32 URL заменой текущих настроек.
